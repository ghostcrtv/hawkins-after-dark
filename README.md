# Leighton's Hawkins After Dark

An unofficial, fan-made trivia game for iPad and iPhone. Made for Leighton, by Steve R.

Four modes: **The Vanishing** (pick-a-path story, 12 endings), **Final Exam** (75 trivia questions across five seasons),
**Flickering Lights** (memory match, five levels) and **Code Red** (a three-act mission).

Plain HTML/CSS/JS, no build step. Host with GitHub Pages, open in Safari, Share > Add to Home Screen.
To use your own music, see `music/README.txt`.

Not affiliated with, endorsed by, or connected to Netflix or the makers of Stranger Things. All art and music are original.
