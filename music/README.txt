OPTIONAL: your own music.
The game plays its own built-in synth score. To use your own tracks instead (for example
royalty-free synthwave from Envato Elements), put MP3 files in this folder with these exact names:

  menu.mp3    - main menu
  story.mp3   - The Vanishing (story mode)
  trivia.mp3  - Final Exam (trivia)
  match.mp3   - Flickering Lights (matching)
  code.mp3    - Code Red

Any track you leave out keeps using the built-in synth.
